# Qt component notices

These are the upstream license and copyright blocks from Qt 6.11.1.
The module lists include platform-conditional components as a conservative
superset; this is not a claim that every component is linked on Windows.
The original Qt SBOMs are in `qt-sbom/` and include SDK tools and unused modules
as well as runtime libraries. They must not be read as an application inventory.
Choose the FTL option for FreeType/rasterizer and the LGPL-3.0 option for Qt.
