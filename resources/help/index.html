FoamAirplaneStudio

Project files

File > New starts an empty project. Open restores a .foam project. Save writes the current project; Save As chooses another filename. Close Project clears the editor but keeps the app open. New, Open, Close and app exit offer Save, Discard or Cancel when there are unsaved changes.

Projects store the reference filename and embedded page images, units and scale, all sketches including fuselage Top/Side outlines and their roles, station attachments, airfoil assignments, per-panel dihedral and lightening, control-surface and spar settings, unfinished sketches, current mode, viewport tab, 2D zoom/position and 3D camera. External reference and airfoil files are not required to reopen a saved project. The 3D model is regenerated from its saved inputs. The title shows the filename and a mark when the project has changed.

The bottom center of the 3D view contains Fit View, Reset, Top, Bottom, Front, Back, Left, and Right buttons. They perform the same commands as the View menu.

Reference

Start in Reference. To unlock Wing, enter Wingspan, or load an image and select a valid Use Reference Image Scale option. An image alone does not unlock Wing. Clearing Wingspan locks Wing again. Fuselage becomes available after every Wing station has an airfoil; its Outline tool supports independent Top and Side sketches.

Choose Load Image to open PNG, JPG/JPEG, or PDF artwork in the 2D background. All pages of a PDF load below one another. The loaded path appears below the button.

File and folder dialogs remember their last accepted selection, including after New or restarting the app. Cancel leaves the remembered selection unchanged.

Loading or resizing fits the image/page stack to the viewport width. Use the mouse wheel to zoom around the cursor and the scrollbars to scroll explicitly. Fit View restores width fitting.

Choose Use Reference Image Scale to use the file's physical image/page size and units. This choice is unavailable for raster images without physical resolution metadata. PDF page units display as inches; metric image metadata displays as mm.

Choose Specify Dimensions to select Project Units and enter a positive decimal Wingspan value, which scales all project lengths using the traced full wing span. Entries accept mm/in suffixes and retain their entered text and physical size when project units change. Full Wingspan scales the traced half-wing and its mirrored partner uniformly; page margins are not assumed to be part of the aircraft.

The reference and dimensions remain when switching component tools. New clears them. The reference appears only in 2D. Use the View menu for fit/camera commands.

Wing, Fuselage and Stabilizer editors are implemented as described below. Assembly provides positioning and reversible mating cuts. Export becomes available after Assembly generation and writes selected former STEP/DXF/SVG/STL and component STEP/STL files.

Wing tools

Outline is the first available Wing tool. Defining it unlocks Airfoil Stations, then Airfoils, then Dihedral. With assigned airfoils, Ailerons/Flaps, Spars, and Lightening are enabled together. Zero-degree dihedral defaults already count as defined. Earlier steps remain editable. Ailerons/Flaps, Spars and Lightening are implemented.

In Wing / Airfoils, load a .dat file or use Sketch Airfoil to trace a named profile. Select an airfoil radio button and click an unassigned station to assign it. Clicking an assigned station displays its own airfoil choice; changing the radio changes only that station. A station is automatically selected on entering Airfoils. Escape and clicks away from stations keep it selected. Assign every station on every panel to unlock Dihedral and automatic 3D generation.

Sketch Airfoil asks for a name. Use the Line/Spline toggles beneath it to draw one closed loop, with leading edge left and trailing edge right. Loading and assignment are disabled while drawing. Click the first point to close a spline, or join multiple curves at their endpoints. Escape or pressing Sketch Airfoil again ends sketching. Invalid or multiple loops produce a warning and are discarded; you can still exit. Profiles and assignments and unfinished sketches are retained in saved .foam projects.

Dihedral has one Root Dihedral angle per panel. The first is relative to horizontal; later angles add to the preceding panel angle. Positive angles raise the tips. The outermost tip is always rounded while preserving its traced outline. Older projects load with zero angles and their former tip choice is replaced by rounding.

With complete outlines and every station assigned, open 3D View in any Wing tool to generate the mirrored wing bodies. Wing edits regenerate the model while viewing 3D, or when you next enter it. Incomplete or invalid inputs clear the old model and show a reason in the status bar. Return to 2D to edit sketches.

In Ailerons/Flaps, check Add Ailerons or Add Flaps and draw a rectangle with two opposite-corner clicks or a drag. Place its hinge edge inside the wing and extend the opposite edge past the trailing edge. Ailerons are magenta; flaps are orange. Escape cancels an unfinished rectangle; Draw Rectangle replaces an existing one. Unchecking disables its cut while retaining the settings.

Tape Hinge Cut keeps top contact with a 45-degree gap below. Standard Hinge Cut keeps center contact with 45-degree gaps above and below. Relief is removed from the control surface only. Both halves contain separate fixed/control bodies. Rectangles must not overlap. An overlapping redraw is rejected with a message in the data panel; draw a replacement or press Escape. Existing overlapping projects can be opened for correction, but cannot generate a wing until corrected. Both spanwise ends have a 1/16-inch (1.5875 mm) clearance removed from the control surface. Cuts are made before mirroring.

When not drawing, click a rectangle to highlight it. Escape clears the highlight; Delete removes the selected rectangle. Draw Rectangle stays lit while drawing; click it again or press Escape to cancel. Leaving Ailerons/Flaps or selecting 3D unchecks any control without a defined rectangle.

Spars

Select a numbered panel tab. Each panel has independent Top, Bottom and Mid options. Chord position is a percentage from local LE; length is a percentage of that panel span starting at its root. Sizes accept mm/in suffixes and retain entered text. Top/Bottom support round diameter or strip width and inward height.

Mid centers the round hole at 50% local thickness at the chosen chord position. Only the main wing panel is split into upper/lower bodies through that center; the split follows its height along the spar, then continues at that height to the panel tip. Ailerons and flaps remain intact.

Matching alignment tabs and holes follow the split at 20% and 80% panel span on both sides of Mid, about 3 mm from the spar. Tabs have 3 mm diameter and 2 mm minimum engagement; holes include 0.1 mm radial/depth allowance.

Files now save as version 32. Version-3 global spar settings load into Panel 1; other panels start disabled. Configure outboard panels explicitly. Versions 1/2 open with all spars disabled. All spars are assumed to be Carbon Fiber. Mid-height spars have Outside Diameter and Inside Diameter fields, initially 6 mm and 5 mm; both accept mm or in. Until edited, Inside Diameter follows Outside Diameter minus 1 mm (minimum zero). Zero means a solid rod, and Inside Diameter must be smaller than Outside Diameter. Tab selection is saved but does not dirty the project or regenerate geometry. Spar errors identify the panel and option.

In Airfoil Stations, hover near an outline for a moving point, then click LE and TE in order. Keep clicking pairs to add stations. Near-horizontal/vertical stations snap within 15 degrees. Two stations on every panel unlock Airfoils.

Click a station to highlight it for Delete. Click an endpoint, slide it along its outline, then left-click or press Escape to drop it; aligned stations move both endpoints together. Escape also cancels incomplete placement and clears selection. Outlines are locked in this mode; stations are locked when you leave it. Station locations are retained in saved .foam projects.

In Wing / Outline, set the number of wing panels and select a numbered tab. Reducing the count removes the highest-numbered panels and their outlines. All outlines stay visible, but only the selected panel can be edited.

Choose Line and click two points, or choose Spline and click multiple points, then press Escape to finish. Tools stay selected for the next curve; click the selected button again to turn it off. Switching tools or tabs also finishes a curve. A lone point is discarded. Nearby points snap within eight screen pixels.

With both tools off, left-click and hold a point to drag it. Connected curves follow their shared points. Inner panels need separate leading and trailing edge chains; the last panel joins them through the tip, leaving the root open.

With both tools off, click a line or spline to highlight it in orange, then press Delete to remove it. Click empty space or press Escape to clear selection. Only the selected panel's curves can be edited. Outlines remain visible when switching tools or workspaces; deleting one curve preserves shared points still used by other curves.

Panel stations, airfoils and controls

Airfoil Stations, Airfoils and Ailerons/Flaps have numbered tabs matching the outline panels. Edit stations and control rectangles only on the selected panel. Every panel needs two stations and assigned airfoils. All imported and sketched airfoils appear in the shared library for every panel. Each station keeps its own assignment. Each panel keeps its own aileron/flap settings, and rectangles must not overlap across panels. The 3D wing uses each panel's own profiles and cuts; only the outer panel gets a shaped tip.

Older global control settings load into Panel 1. Review older multi-panel projects and add the station pairs and controls needed on their other panels.

Lightening

Enable Lightening to hollow the main wing. Set minimum Wall Thickness, Number of Crossmembers, Crossmember Thickness, Start Distance from Root and Stop Distance before Last Station. Distances follow the unfolded half-wing; physical fields accept mm/in and retain their text. Main panels split for access even without Mid spars. Controls and tips stay solid, and alignment pins/sockets retain support. Pockets have stepped floors and ceilings and may retain more than the minimum wall thickness.

Regeneration and cancellation

Generation runs in the background with bounded panel concurrency. Menus, shortcuts, tools, data fields and viewports are disabled while processing; Cancel remains at the bottom of the data panel. Cancellation is cooperative and can wait for the current kernel operation. It retains the previous display and source inputs. Re-enter 3D View or edit an input to retry; toolbar navigation alone does not restart a cancelled job. Successful replacement retains the camera. Closing waits for cancellation before the usual unsaved-change prompt.

Camera, navigation and idle selection changes are saved on explicit Save but do not cause unsaved-data prompts or rebuild unchanged geometry.

Fuselage Outline

Select Fuselage, then Outline. Click Top View or Side View to activate it; both buttons remain enabled so you can switch directly. Clicking the active view again releases it. Line and Spline appear beneath the selected view and work like Wing outline tools: draw segments, finish a spline with Escape, snap endpoints together, or turn both tools off to drag points and select/Delete curves. Click the first spline point to close it.

Trace one closed outline for each view. Leaving Outline or switching to 3D checks both and warns which view is incomplete, without discarding your sketches. Two valid outlines enable Profile Stations while Outline remains selected. Profile Stations supports vertical Side View sections; A station or an existing profile enables Edit Profiles. Save/Open preserves both outlines, view selection and unfinished drawing.

Fuselage Profile Stations

Hover near the top or bottom edge of the Side View outline to see a green floating point and a vertical section preview. Left-click once to place the station, then move to the next location. Start near the nose and add stations where the shape changes. Only sections with two distinct boundary intersections can be placed. Top View and both outlines stay locked.

Click a station line to select it; Delete removes it. Click an endpoint, move along its outline, then left-click or Escape to drop it. The section stays vertical. Escape clears selection. Stations stay attached to edited outlines, and Save/Open preserves them independently from Wing stations.

Fuselage Edit Profiles and 3D

Copy Profile lets you click a source profile. Select a destination station and click Paste Profile to assign an independent copy, replacing that station's existing profile. The copy appears in open space beside the drawing. Move Profile lets you press and hold on any profile, drag the whole shape, and release to drop it. Escape ends Copy or Move mode.

The model uses the right half of each profile and mirrors it across the fuselage centre plane. The full Top View width and Side View height set its size. Traced left/right differences are intentionally removed in the model; the drawing is unchanged. The left and right main fuselage halves remain separate parts, while formers and the servo tray remain whole.

Circle sits below Line/Spline and is mutually exclusive with them. Click the center, then click a point to set the radius. Escape cancels an unfinished circle. With drawing tools off, drag the center to move it or the radius handle to resize it. Circles are saved with the project. This tool is available in Edit Profiles only.

Click a station to highlight it. Use Line, Spline or Circle to draw one closed cross-section anywhere over the reference. Width runs left/right and height up/down. Turn the drawing tool off to move points, Delete a selected curve, or select another station. Delete Profile clears the entire assigned sketch. Profiles remain attached when stations move.

When every station has a closed loop, the remaining secondary actions become available (Thicken, Cut, Servo Tray and Formers are implemented). Open 3D View to generate using saved/default wall thickness in a separate cancellable worker. Thicken, Cut, Servo Tray and Formers need not be opened. Completing the outlines and station profiles enables Horiz Stab and Vert Stab; stabilizer Outline, Airfoil and 3D generation are implemented; Hinge Line is implemented; Cut supports closed material-removal shapes. Both views align at their leftmost noses and share the fuselage length. Each section fits independently between the Top View sides and the Side View upper/lower edges. The nearest profile supplies the nose/tail shape beyond the outermost stations. Wing and Fuselage models are cached separately.

Stabilizers

In Horiz Stab or Vert Stab, trace one continuous open outline around the leading edge, tip and trailing edge, leaving the root open. For Horiz Stab draw the right half including the elevator; for Vert Stab draw the whole fin including the rudder. Use Line/Spline, Escape to finish, and selection/Delete with the drawing tools off. The root endpoint line must be within 10 degrees of horizontal or vertical.

Choose Select Leading Edge End Point, then click the open root endpoint at the leading edge. The green LE marker sets airfoil orientation and is required for generation. Airfoil defaults to NACA009; Load Airfoil .dat File assigns one profile to the entire stabilizer. Open 3D View to generate one joined horizontal stabilizer or one vertical fin. A hinge cut leaves two bodies: the joined stabilizer and joined elevator, or the fin and rudder. The Cancel button appears at the bottom of the data panel only during regeneration. In manual-reference mode, scale comes from Wingspan and the traced full wing span, so the drawings must share a scale. Each stabilizer has its own cached model. Older projects require a leading-edge selection before generation. Hinge Line lets you draw connected straight segments across the outline to separate the elevator/rudder. For vertical fins, the segment closest to the upright span direction receives the bevel; horizontal stabilizers use the longest segment. Other connected segments remain square cuts. The selected segment receives Tape Hinge Cut (upper-surface contact, 45-degree gap below) or Standard Hinge Cut (middle contact, gaps above/below). Start and end on or beyond the outline. Escape finishes drawing; drag points or select a segment and Delete when drawing is off. In Cut, use Add Cut Shape to draw a closed Line/Spline loop. Material inside the loop is removed through all intersecting bodies; remaining pieces are retained. Horizontal cuts are mirrored. Select a loop from the list or drawing to edit, and use Delete Cut Shape to remove the loop. With drawing tools off, click a curve to highlight it and press Delete to remove just that curve. Leaving Cut warns about unclosed loops.

Fuselage Formers

Enter Width (thickness) in Reference units or explicit mm/in, then Add Former. A vertical rectangle spans above and below Side View at a free position. Drag inside to slide it horizontally or vertically. A rectangle may cross only one outline edge: the insert follows the cavity and stops at the rectangle height. Thickness retains its entered physical size when Wingspan changes. Move up/down for partial height, or drag its top/bottom handles to resize. Select a former to change its thickness. Rotation Angle below Add Former rotates that former about its center in Side View, in decimal degrees; negative values turn counter-clockwise. Each new former starts at 0. The outline, resize handles and retaining rails follow the angle. Click empty space to set the next thickness. Delete removes the selection.

Formers cannot overlap each other or the servo tray; rejected edits retain the last valid position. Touching is allowed. Default thickness works without editing; zero is invalid. Open 3D View to automatically initialize missing wall defaults and generate separate inserts fitted inside the cavity and clear of walls and tray supports. Integral retaining rails run immediately ahead of and behind each former on both inner sides: 4 mm fore/aft wide and 3 mm inward deep, following the available side height while clearing other inserts. The largest remaining fuselage body is split into left/right halves down the aligned nose centre plane; smaller hatch and other cut-out parts remain whole. Two top and two bottom alignment pins locate the halves near the ends: 3 mm pin projection, 3.5 mm socket depth, and 4 mm diameter capped by local wall thickness. Generation moves pins locally to avoid missing or insufficient seam material and reports an error if all four cannot fit. Rectangles stay visible in other 2D modes and are saved with the project.

Fuselage Servo Tray

Enter Width (fore/aft length) and Height (tray thickness), using Reference units or explicit mm/in. Editing a field creates or resizes a rectangle about its center; Place Rectangle also creates it using the displayed dimensions. Drag the rectangle on Side View to position it. Moving never changes its size; use the fields to resize. Delete removes it. The rectangle stays visible in other 2D modes and is saved with the project.

Open 3D View to generate using the default tray thickness or your entered value. Missing station walls are initialized automatically; existing values are preserved. Zero thickness is invalid. The tray fits the cavity as a separate part. Two ledges join the walls beneath it, extending 5 mm inward and 5 mm down. Cut paths split the supported fuselage; the tray stays separate. Top-face geometry is retained for future DXF/SVG export. Sloping inner walls can give the tray different top and bottom edge contours.

Fuselage Cut

Select Top, Bottom, Left or Right View, then draw connected Line and Spline segments over that outline. Escape finishes a spline. Turn drawing tools off to move points, select a segment or press Delete. Paths need not be closed: an open path must reach or cross the body boundary at both ends. Closed paths can also detach sections. All cut paths remain visible in 2D after changing modes and are saved with the project.

Open 3D View to apply cuts. Paths that reach or cross the outline cut through both opposite walls. Closed loops entirely inside the outline cut only the selected wall, stopping at the cavity. If that cut would hit a parallel wall on another side, generation stops with a status error; move or shrink the loop. In both cases, the cut-out interior remains a separate component. Every resulting body is retained in place; cuts add no kerf or clearance. Generation reports an error if a path does not separate a body. Cuts apply after Thicken when enabled.

Fuselage Thicken

All profile sketches stay visible in every 2D mode. Thicken edits wall values; generation also initializes missing wall defaults automatically, without requiring a visit to this tab. Stations are numbered nose to tail consistently with Edit Profiles; fields appear in ascending numerical order and display Reference units. Bare decimal entries use those units; add mm or in to enter either unit manually. Defaults are 8 mm for every station at or forward of the wing LE and 5 mm aft of it. The Side View wing-seat edge is preferred for locating the LE; the nearest station within 2% of the wing chord counts as the LE station. Edited values stay attached when stations move. Open 3D View to generate the inward wall, smoothly transitioning between station values.

The outside shape follows the outlines. For generation, a straight nose/tail edge within 2 degrees of vertical and 0.5 mm axial drift is registered to a vertical end plane without changing the drawing. Choose Nose Open/Closed and Tail Open/Closed independently in Outline; new projects default to Nose Open and Tail Closed. Open straight slanted ends extend the hollow body to the outline end plane. Legacy projects resolve their previous automatic end choices once when opened. Narrow extended tips stay solid. Excessive thickness or a closed-off interior produces a status error. Save/Open preserves activation and thickness values.

Project files always open in 2D View without model regeneration. Files saved in Assembly open in Fuselage Side View, retaining Assembly positions and cut settings. Select 3D View or Assembly when ready to generate models.

Assembly

After all component definitions are complete, select Assembly. It opens the left-side 3D view with the fuselage centered; 2D View is disabled. Missing component models are generated in the background. The wing starts above the fuselage; the stabilizers start near its tail.

The reference image is aligned behind the fuselage; sketch lines are hidden. Select Wing, Horiz Stab or Vert Stab, then use Left/Right to move toward the nose/tail and Up/Down to raise/lower. Steps are 1 mm, Shift 10 mm, or Ctrl 0.1 mm. The selected component is orange; its control surface moves with it. Rotate Clockwise and Rotate Counter-Clockwise change its angle by 0.5 degrees about the root chord midpoint. The angle appears below the buttons; positive is clockwise in the standard side view, regardless of camera orbit. Angles are saved and support undo/redo. Undo Cuts before rotating a cut assembly. The fuselage and lateral centerline remain fixed. Mouse orbit, pan and zoom remain available. Re-enter Assembly to restore the side view.

Cut Intersections checks only intersections between the rudder and elevator and reports offending parts before cutting. It cuts Wing and fixed stabilizer seats in the fuselage, then a fin slot in the fixed horizontal stabilizer. The wing also cuts seats in formers at its current position and rotation; formers remain separate parts and the servo tray is unchanged. Successful cuts lock the three selectors and change the button to Undo Cuts. Undo restores originals at their current positions. Generated models remain in memory during the session and are not saved. Old embedded models are ignored on Open; selecting 3D or Assembly regenerates them. Original component models stay cached separately; export geometry uses the cut snapshot. Positions and cut intent are saved with the project. Source edits invalidate cuts. In Export, choose Formers STEP, DXF, SVG or STL and Components STEP or STL (STEP is the default for both groups), with All selected initially; uncheck individual parts as needed. Formers are numbered from the nose toward the tail. Export Components asks for an output folder and remembers it. STEP writes one file named after the project (for example, My Plane.step); DXF/SVG/STL write individual named files. Former DXF and SVG use a full-size local mid-plane section in millimeters.

To recover a fuselage profile after deleting and replacing its station, open Edit Profiles, select the unassigned station, turn Line/Spline/Circle off, and double-click the unassigned profile. Single-click an unattached profile to highlight it, then press Delete or Delete Profile to remove it, even if no stations remain. Undo/Redo restores or removes this assignment.

In Wing > Airfoils, select an airfoil in the list and click Export Selected Airfoil .dat. The file contains its name and 69 cosine-spaced coordinates from upper trailing edge through leading edge to lower trailing edge, with LE at x=0 and TE at x=1. Imported and sketched airfoils are supported.

In Wing > Airfoils, Smooth Airfoil previews the selected outline in blue and the smoothed copy in orange. Adjust the strength slider and compare maximum thickness and camber. Short, steep closing edges at the trailing edge are kept separate from the fitted surfaces, preventing a hook into the closing line. The larger preview dialog is resizable. Save Copy adds a named airfoil without changing the original or station assignments; select the copy in the list to use it. Cancel discards the preview. DAT export remains limited to 69 data points.

Undo and Redo

Edit > Undo (Ctrl+Z) and Edit > Redo (Ctrl+Y) restore project edits across all editors, including sketches, stations, profile copies, movements, formers, servo trays, RC parts and Assembly placements. A drag is one edit. New and Open start a fresh history; Save retains it. With Line/Spline/Circle off, click an individual curve to highlight it in orange, then press Delete.

Fuselage Holes and Cut

Holes offers Top, Bottom, Left and Right walls. Choose a wall, Add Hole, and draw a closed loop with Line/Spline entirely inside the corresponding outline. Top/Bottom use Top View; Left/Right use Side View. Select a hole from the list and use Delete Hole to remove it. Incomplete loops warn when leaving Holes. Generation cuts only the selected wall, stopping at the cavity; move or resize holes whose footprint cannot safely reach the cavity. Cut uses matching Add Cut, path selector, Line/Spline and Delete Cut controls for multiple independent paths; Cut uses the four surfaces too: boundary-crossing paths split both walls, while interior loops detach only the selected wall. Both retain cut-outs as components.

Fiberglass (Weight and Balance only)

Wing, Fuselage, Horiz Stab and Vert Stab have a Fiberglass tool. Add a shape and draw connected Lines/Splines or a Circle over the component outline. The overlapping region receives cloth and resin. Open paths are allowed when their endpoints can be joined outside the component outline. Select a shape to edit its name, Wrap Sides/One Sided mode, drawing surface and cloth weight. Top/Bottom use the fuselage Top View; Left/Right use Side View. Wing and horizontal stabilizer shapes follow both mirrored halves. Overlapping shapes add layers.

Cloth units default to g/m² or oz/yd² from Reference units and can be converted independently. Resin thickness is estimated from cloth weight; disable estimation to enter your own thickness. Generate the current Assembly to estimate covered exterior surface area, mass and CG. Fiberglass never changes manufactured geometry. Invalid or unfinished shapes keep full weight/CG unavailable until corrected.

Weight and Balance

The Weight and Balance toolbar tab opens the 2D fuselage Side View. Add Part opens a dialog for a unique name, decimal Width, Height and Length in Reference units, and weight in grams or ounces. Width extends into the screen; Length and Height size the labeled rectangle. New parts appear centrally. Drag them to position, select from the list or diagram, and use Edit or Delete. Parts appear only in this tab.

Foam density starts at 25.63 kg/m³ for XPS. Aero Plywood density starts at 680 kg/m³ for formers and the servo tray. Carbon Fiber density starts at 1540 kg/m³ for all enabled wing spars. Material Densities opens a dialog for these values and Resin density, initially 1180 kg/m³ for cured solvent-free laminating epoxy. OK applies changes; Cancel preserves the previous values. Current Assembly geometry supplies the volumes and centroids, including active cuts. Wing spars are counted automatically: solid surface rods/strips and hollow mid tubes, excluding the bore. Carbon Fiber appears in the component table, material subtotals and overall weight/center of gravity. Fiberglass sketches add separate cloth and resin rows and subtotals using covered surface area. Add other unmodeled material as parts; do not count fiberglass twice. Totals update after edits; center of gravity is measured from the placed wing root leading edge in Reference units, positive toward the tail and negative toward the nose. Each added part's mass acts at its rectangle center. The small CG symbol marks the calculated distance from the wing leading edge, at 20% of maximum root airfoil thickness above its lowest point. Its vertical placement is a visual reference, not a calculated vertical CG.

Generate and position the current Assembly for a complete calculation. Without it, only the entered parts subtotal is available. Saving retains parts, positions and densities; opening stays in 2D without generating geometry.

Inspect

Inspect regenerates changed or missing components with complete definitions and reuses unchanged models. It lists individual solids, using the placed/cut Assembly when available. Progress and Cancel work as in the modeling tabs. Checked components appear in 3D; uncheck any component to hide it. All components start checked. Edit a name and press Enter or leave its field to save it. Names persist in the project and are used by Export and DXF/SVG/STL filenames. Use unique names without filename punctuation such as slashes or colons. STEP output uses the project name, or Untitled before the project is saved. Inspect visibility does not change export selection or model weight. Camera buttons, orbit, pan and zoom work normally; 2D is disabled in this mode.

Airplane statistics

Available statistics appear at the bottom of data panels except Assembly, Export and Weight and Balance, above their bottom buttons. Lists and tabs shorten to make room. The summary shows Wingspan, Wing Area, Root Chord, Aspect Ratio, Fuselage Length, horizontal and vertical stabilizer areas, Weight, Wing Loading and CG from the placed wing root leading edge (positive toward the tail). Dimensions and areas follow Reference units. Wing Loading uses g/dm² or oz/ft².

Areas use the nominal unfolded outlines, including both wing and horizontal stabilizer halves, before cutouts. Weight and CG use Assembly material measurements and added parts. Statistics are saved with the project; changes update available values and hide stale mass results until Assembly is current. Statistics never trigger model generation. Assembly movements and entering Export do not recalculate weight and balance; stale mass values remain invalid until a relevant mode refreshes them. Weight and Balance keeps its existing display and adds Wing Loading, without the shared footer.
