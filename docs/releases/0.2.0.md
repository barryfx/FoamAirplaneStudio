# FoamAirplaneStudio 0.2.0

Source release: October 4, 2026. Project format: 33 (reads versions 1–33).
Windows, Ubuntu and Fedora installers, source archives and SHA-256 checksums
are available on the [Releases page](https://github.com/barryfx/FoamAirplaneStudio/releases/).
The existing `v0.2.0` source tag is unchanged. Installers include the license
manifest correction recorded in commit `4cead45`; supplied source archives
include that correction as well.

## Changes since 0.1.0

- Add Fiberglass tabs for Wing, Fuselage, Horiz Stab and Vert Stab. Covering
  sketches estimate cloth/resin mass and balance without changing geometry.
  Cloth and resin rows use the same covered area; resin defaults to 1.5 g/cm³.
- Calculate mass statistics only in Weight and Balance. Reuse unchanged
  component and covering measurements and use up to 90% of logical threads
  for independent measurements.
- Add 0–3 carbon stiffeners per fuselage side, mirrored after cutting. Strip
  and round routes are straight in Side View between endpoint height fractions,
  follow the skin laterally, and maintain constant inward depth. Top View can
  therefore show curvature. Bounded lofts avoid tool overshoot; rejection
  diagnostics include the affected longitudinal location where available.
- Cache fuselage geometry after support-rail generation so downstream changes
  can reuse that stage. Reuse stiffener clearance classifiers.
- Preserve entered distance units through editing and Save/Open. Stiffener
  dimensions default to mm independently of project units.
- Distinguish cuts and holes with dedicated colors in the 2D views.
- Update the BabyBuzzard example to format 33 with fiberglass and one strip
  stiffener per side. This example needs 0.2.0; 0.1.0 cannot read format 33.
