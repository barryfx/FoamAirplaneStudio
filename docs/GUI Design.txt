Wing toolbar availability:
Outline is initially selected and is the only enabled Wing tool.
Defining Outline enables Airfoil Stations; defining stations enables Airfoils;
defining airfoils enables Dihedral. Its zero-degree panel defaults count as defined.
Defining Dihedral enables Ailerons/Flaps,
Spars, and Lightening together. Previously enabled tools remain editable.

Implemented panel details are maintained in docs/architecture: reference.md,
sketch-editor.md, airfoil-stations.md, airfoils.md, dihedral.md, wing-solids.md,
control-surfaces.md and spars.md. The drawing above includes planned editors;
it is not a claim that all illustrated tools/statistics are implemented.

Wing / Lightening
Descriptive text explains minimum walls, access split, solid controls/tip,
uniform crossmembers and unfolded span distances. Enable Lightening checkbox;
Wall Thickness; Number of Crossmembers; Crossmember Thickness; Start Distance
from Root; Stop Distance before Last Station. Physical entries accept mm/in
and retain entered text. Pins and sockets retain wall-thickness support.

Regeneration: wing panels run as independent, bounded background tasks. Disable
menus, shortcuts, toolbars, data fields and viewport controls while processing;
show Cancel at the bottom of the data panel. Report panel-specific status and
restore controls on completion, failure or cooperative cancellation. Keep the
last display on cancellation and retain the camera on successful replacement.
Fuselage has its own worker and cached solid; Wing rebuilds only for changed Wing inputs. Stabilizers also own independent cancellable workers and cached solids.

Fuselage / Outline: instructions above Top View and Side View toggle buttons.
The selected view lights up and shows Line/Spline beneath it. Both selectors stay
enabled for direct switching; clicking the selected view releases it. Both views
require a closed loop. Warn by view name on leaving Outline, retaining sketches.
Two valid outlines enable Profile Stations; Outline stays checked until navigation.

Fuselage / Profile Stations: instructions at the top. Hover on the Side View upper
or lower edge for a floating point and vertical preview. Left-click once to place
the section. Select/Delete or click an endpoint to move it, with vertical alignment.

Implemented Fuselage Edit Profiles: a station or an existing profile enables the mode. Instructions
appear above Line/Spline/Circle controls for the selected highlighted station. Each
station owns a stable sketch assignment. All closed assignments enable remaining
secondary actions. Thicken, Cut, Servo Tray, Formers and Stiffeners are implemented. Selecting 3D generates a solid
from both nose-aligned outlines and independently fitted profiles. See
architecture/fuselage-profiles.md for registration, sampling and end treatment.

Fuselage / Thicken: instructions above decimal length fields in ascending station
number order, numbered nose to tail consistently with Edit Profiles. Fields display Reference units; bare values use those units, and
explicit mm or in entries are accepted. Defaults are 8 mm for every station at or forward of the Side View wing-seat leading edge and 5 mm aft.
Entering this tool or generating a complete fuselage initializes missing defaults
and enables persistent inward hollow generation, without overwriting entered values.
The user need not visit Thicken before generation. Walls have smooth
transitions between station values. Outline has independent Nose Open/Closed and
Tail Open/Closed choices, defaulting to Nose Open and Tail Closed. Legacy automatic
choices are resolved once on load. Explicit open straight slanted ends retain the
drawn plane; pointed/undersized openings may be rejected. All profile sketches
remain visible across 2D modes.
See architecture/fuselage-thickness.md for the offset convention and persistence.

Fuselage / Cut: instructions, Top/Bottom/Left/Right selectors and Line/Spline controls.
Reuse standard sketch editing, snapping, selection and Delete. Boundary-crossing
paths cut both walls; closed interior paths detach only the selected wall at the
inner cavity. Reject parallel-wall interference. Preserve every cut-out component.
Cut sketches remain visible across 2D modes; format 31 migrates legacy Side to Left.
Generate mirrored, separate main halves, retaining four alignment pins. Rejoin
detached cut-outs across the seam; keep tray/formers whole (ADR-0045/0049/0032).

Fuselage / Servo Tray: instructions above Width, Height, Place Rectangle and Delete Tray.
Enter dimensions in Reference units (or explicit mm/in), then drag the fixed-size
rectangle on Side View. Edit fields to resize about its center. Height sets tray thickness. Thicken
provides the inner cavity. A separate cavity-fitted tray sits on side ledges
extending 5 mm inward and 5 mm down. Retain top-face geometry for later laser
export. Persist the dimensioned rectangle; keep the completed rectangle visible.

Fuselage / Formers: instructions above Width (thickness), Add Former, Rotation Angle and
Delete Former. Rotation Angle is directly below Add Former, defaults to 0 for
each new former, and applies to the selection in decimal degrees. Rotate about
the mask center in Side View; negative is counter-clockwise. Add creates a full-height Side View rectangle; drag to move in either
axis, or drag the top/bottom handles to change height. Width uses Reference units
or explicit mm/in. Prevent overlap with formers or the tray in either editor.
Generate separate cavity-fitted solids, clear of walls/supports. Add 4 mm fore/aft
by 3 mm inward retaining rails ahead of and behind each former on both cavity
sides, clearing removable inserts. Rotate masks, local height handles and rail
slabs together. Persist placements and per-former angles.

Stabilizers / Outline: shared Line/Spline editing with one independent open outline
per component. Horizontal instructions request the right half including elevator,
for later mirroring, and explain later rudder-clearance cuts. Vertical instructions
request the complete fin including rudder, without mirroring. The line through both endpoints must be
within 10 degrees of horizontal or vertical, including 90-degree rotated drawings.
Warn on leaving Outline or entering 3D for disconnected/closed/branched paths,
coincident endpoints, or endpoint lines more than 10 degrees from either axis.
Retain all sketches after warnings. Select Leading Edge End Point lets the user choose either open root end and marks it LE. The outline is invalid until selected. Save/Open preserves both outlines, leading-edge selections and drafts.
Airfoil shows "Load the airfoil to use for the stabilizer from a .dat file.", then
"Load Airfoil .dat File" and the loaded DAT name. Bundle naca009.dat as the default,
even before Airfoil is visited. Enable other tools only after a valid Outline.
Entering 3D generates that stabilizer in its own worker with progress and Cancel.
Hinge Line draws connected segments and applies Tape/Standard relief on the segment closest to span direction for vertical fins, or the longest segment for horizontal stabilizers. Other segments remain square cuts. Cut supports closed material-removal shapes. See architecture/stabilizer-solids.md.

Assembly: on entry disable 2D View, activate 3D and show the left side centered
on the fuselage. Select a component to translate with arrow keys (1 mm, Shift
10 mm, Ctrl 0.1 mm). Cut Intersections validates rudder/elevator clearance, cuts
fuselage seats and the horizontal fin slot, locks positioning and becomes Undo
Cuts. Retain original caches and export the cut snapshot. See architecture/assembly.md.

Fuselage Holes: Top/Bottom/Left/Right; Add Hole; hole selector; Line/Spline; Delete Hole. Closed loops remain inside the selected outline and remove one wall only. Fuselage Cut uses the same four surface choices with Add Cut and Delete Cut, retaining detached pieces.

Weight and Balance: 2D Side View; instructions, Add Part, named parts list, Edit/Delete, XPS, Aero Plywood and Carbon Fiber densities. Part dialog: Name, Width/Height/Length in Reference units, weight in grams/ounces. Drag labeled rectangles; show only in this mode. Bottom total, Wing Loading and Center of Gravity relative to placed wing root LE, positive aft. A small CG marker uses that distance, with visual height 20% above the root airfoil's lowest point through its maximum thickness. See architecture/weight-and-balance.md.

Inspect: after Assembly, before Weight and Balance and Export; 3D only. Show a vertical checkbox/name
list for all current generated components. All begin checked. Names are editable
and persist for Export and individual filenames. STEP uses the project name.

Edit Profiles also provides Copy Profile, Paste Profile and Move Profile. Single-
click unattached profiles to highlight/delete them, even with no stations. To
recover an orphan, select an unassigned station and double-click its profile.
Undo/Redo covers these operations and other project editors.

Reference uses Use Reference Image Scale or Specify Dimensions. Specify
Dimensions exposes Project Units and Wingspan; no Fuselage Length input remains.

The 3D viewport has bottom-centered Fit View, Reset, Top, Bottom, Front, Back,
Left and Right buttons using the same actions as View. Fuselage generation
registers nearly vertical straight end edges within 2 degrees/0.5 mm and treats
outermost profiles within 0.5 mm of those end planes as open ends. Drawing data
is unchanged; this describes legacy automatic end inference (ADR-0044), superseded
for current projects by the explicit end choices in ADR-0048/0049.

Fuselage / Stiffeners: Number of Stiffeners is per side, mirrored on both sides.
Zero disables grooves. Shape selects Strip (Width vertical, Height inward) or
Round (one Diameter). Start and Stop are percentages from the nose. Lengths use
Reference units or explicit mm/in. One route follows local mid-height; multiple
routes are evenly spaced, with smooth lofts and checks against abrupt bends and
wall breakthrough. Regenerate in 3D; Weight and Balance includes solid carbon
stock. See architecture/fuselage-stiffeners.md.
