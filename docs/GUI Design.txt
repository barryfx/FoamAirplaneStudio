Wing toolbar availability:
Outline is initially selected and is the only enabled Wing tool.
Defining Outline enables Airfoil Stations; defining stations enables Airfoils;
defining airfoils enables Dihedral. Its zero-degree panel defaults count as defined.
Defining Dihedral enables Ailerons/Flaps,
Spars, and Lightening together. Previously enabled tools remain editable.

Implemented panel details are maintained in docs/architecture: reference.md,
sketch-editor.md, airfoil-stations.md, airfoils.md, dihedral.md, wing-solids.md,
control-surfaces.md and spars.md. The drawing above includes planned editors;
it is not a claim that all illustrated tools/statistics are implemented.

Wing / Lightening
Descriptive text explains minimum walls, access split, solid controls/tip,
uniform crossmembers and unfolded span distances. Enable Lightening checkbox;
Wall Thickness; Number of Crossmembers; Crossmember Thickness; Start Distance
from Root; Stop Distance before Last Station. Physical entries accept mm/in
and retain entered text. Pins and sockets retain wall-thickness support.

Regeneration: wing panels run as independent, bounded background tasks. Disable
menus, shortcuts, toolbars, data fields and viewport controls while processing;
show Cancel at the bottom of the data panel. Report panel-specific status and
restore controls on completion, failure or cooperative cancellation. Keep the
last display on cancellation and retain the camera on successful replacement.
Fuselage has its own worker and cached solid; Wing rebuilds only for changed Wing inputs. Stabilizers also own independent cancellable workers and cached solids.

Fuselage / Outline: instructions above Top View and Side View toggle buttons.
The selected view lights up, disables the other view, and shows Line/Spline beneath
it. Clicking it again releases the view. Reuse Wing sketch controls; both views
require a closed loop. Warn by view name on leaving Outline, retaining sketches.
Two valid outlines enable Profile Stations; Outline stays checked until navigation.

Fuselage / Profile Stations: instructions at the top. Hover on the Side View upper
or lower edge for a floating point and vertical preview. Left-click once to place
the section. Select/Delete or click an endpoint to move it, with vertical alignment.

Implemented Fuselage Edit Profiles: one station enables the mode. Instructions
appear above Line/Spline controls for the selected highlighted station. Each
station owns a stable sketch assignment. All closed assignments enable remaining
secondary actions. Thicken, Cut, Servo Tray and Formers are implemented. Selecting 3D generates a solid
from both nose-aligned outlines and independently fitted profiles. See
architecture/fuselage-profiles.md for registration, sampling and end treatment.

Fuselage / Thicken: instructions above decimal length fields in ascending station
number order, numbered nose to tail consistently with Edit Profiles. Fields display Reference units; bare values use those units, and
explicit mm or in entries are accepted. Defaults are 8 mm for every station at or forward of the Side View wing-seat leading edge and 5 mm aft.
Entering this tool enables persistent inward hollow generation, with smooth
transitions between station values. Both ends follow the same rule: open when
outlines end at the outermost profile, closed when they extend beyond it. Narrow
extended tips remain solid. All profile sketches remain visible across 2D modes.
See architecture/fuselage-thickness.md for the offset convention and persistence.

Fuselage / Cut: instructions, Top/Side selectors and Line/Spline controls.
Reuse standard sketch editing, snapping, selection and Delete. Open connected
paths may run edge to edge; closed paths are also supported. Cut through full
height from Top or full width from Side, preserving all separated bodies.
Cut sketches remain visible across 2D modes and are saved in project version 13.

Fuselage / Servo Tray: instructions above Width, Height, Place Rectangle and Delete Tray.
Enter dimensions in Reference units (or explicit mm/in), then drag the fixed-size
rectangle on Side View. Edit fields to resize about its center. Height sets tray thickness. Thicken
provides the inner cavity. A separate cavity-fitted tray sits on side ledges
extending 5 mm inward and 5 mm down. Retain top-face geometry for later laser
export. Persist the dimensioned rectangle; keep the completed rectangle visible.

Fuselage / Formers: instructions above Width (thickness), Add Former and Delete
Former. Add creates a full-height Side View rectangle; drag to move in either
axis, or drag the top/bottom handles to change height. Width uses Reference units
or explicit mm/in. Prevent overlap with formers or the tray in either editor.
Generate separate cavity-fitted solids, clear of walls/supports. Persist placements.

Stabilizers / Outline: shared Line/Spline editing with one independent open outline
per component. Horizontal instructions request the right half including elevator,
for later mirroring, and explain later rudder-clearance cuts. Vertical instructions
request the complete fin including rudder, without mirroring. The line through both endpoints must be
within 10 degrees of horizontal or vertical, including 90-degree rotated drawings.
Warn on leaving Outline or entering 3D for disconnected/closed/branched paths,
coincident endpoints, or endpoint lines more than 10 degrees from either axis.
Retain all sketches after warnings. Select Leading Edge End Point lets the user choose either open root end and marks it LE. The outline is invalid until selected. Save/Open preserves both outlines, leading-edge selections and drafts.
Airfoil shows "Load the airfoil to use for the stabilizer from a .dat file.", then
"Load Airfoil .dat File" and the loaded DAT name. Bundle naca009.dat as the default,
even before Airfoil is visited. Enable other tools only after a valid Outline.
Entering 3D generates that stabilizer in its own worker with progress and Cancel.
Hinge Line and Cut remain planned editors. See architecture/stabilizer-solids.md.
